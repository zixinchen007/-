# 连续慢跑与离线预览

连续慢跑是主 CLI 与 Python 门面的默认模型，显式 `--motion-model legacy` 可使用旧匀速模型。

运动时间线统一提供速度、累计距离、步频、累计步数和距离反查；GPS 位置、地图字段和 10 秒统计均复用同一来源。随机种子用于同版本同输入的复现，不代表真人测量数据。

```powershell
.\preview.cmd --distance 2537 --time-sec 1183 --seed 42
```

预览不加载会话，不构造登录客户端，不访问真实网络。默认使用虚构示意跑道，HTML 和 JSON 保存到 `.local/previews/`。支持自备路线、参考点位和输出目录。

模型对比包含匀速和连续慢跑；选择 V3 时另加 V3 结果。曲线展示累计数据、速度、步频与步幅，统计检查覆盖总量、时间戳、配速单位和末尾不足 10 秒的窗口。

离线一致性不等于实时学校规则通过；本仓库不提供真实账号、设备标识、学校路线或跑步记录。安装与在线参数参见根目录 README。
