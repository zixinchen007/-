# V3.2 实验模型

通过 `--motion-model v3` 或 Python 的 `MotionV3Options` 显式选择；默认仍是连续慢跑 `jog`。

```powershell
.\preview.cmd --motion-model v3 --distance 5000 --time-sec 2401 --seed 42 --lap-variation
```

该命令只做离线预览，不登录、不上传。默认示意跑道不是实测数据。HTML/JSON 位于 `.local/previews/`。

## 数据流与修复

先调用 builder 准备最终路线、点位和微变几何，再以同一份 `PreparedRoute.motion_route` 求解速度、距离和区间步频。采样复用最终路线，不再次生成几何。

`motion-v3-python-2` 修复按秒前瞻漏过秒内急弯的问题：检查所有可穿越顶点，为下一顶点保留制动距离；根据最低弯道速度构造可由非负秒级速度表达的保守制动包络，并平滑上限响应，避免恰好擦过顶点时距离求解跳变。

独立后校验保留：以 `v²=v0²+2aΔs` 计算穿越顶点速度，横向加速度超过配置上限加 0.1 m/s² 即停止构建，不放宽阈值或自动回退。距离残差目标为 1e-8 米、接受上限为 1e-7 米；累计末点不通过强制赋值伪造。V3 步数采用正数半进位取整。

## 验证与限制

测试覆盖起停、加减速、积分、距离反查、种子复现、秒内急弯、低速发卡弯、虚构路线微变及人为超速后的拒绝。测试使用模拟客户端，不能推断真实成绩或 App 最终显示。

模型未经真人记录校准；不保证连续加速度、全程 jerk 或所有路线均可求解。非常密集的小弯仍受离散曲率估计影响。配置无效、不可行或不收敛时停止生成。
